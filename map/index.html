Digital Object 4: Geospatial Structures

This section explores geospatial data visualization using Mapbox GL JS, demonstrating how to create interactive maps with markers, line features, and polygon regions. These examples show how to represent different types of spatial data and create engaging user experiences.

Mapping Surveillance Cameras in NYC

This map shows the location of surveillance cameras in NYC. This dataset was created by a series of volunteers who went around the city and jotted down the locations of surveillance cameras in an effort to bring awareness to the growing presence of surveilance technologies in our neighborhoods.
